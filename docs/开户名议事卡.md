# 开户名议事卡

| 项 | 值 |
|----|-----|
| 议题 | 柜面开户缺当事人姓名（空名）的名册口径 |
| 封板日期 | 2026-11-22 |
| 拍板 | **甲路径：空名拒开户** |
| 状态 | 已封板，当日不得翻案 |

## 封板口径（甲路径）

1. 开户请求当事人姓名为空或全空白 → **拒写**，HTTP 422。
2. 账户正式表 `bond_accounts` **零增长**，入金流水 `deposit_ledger` 零写。
3. 拒写必记：审计表 `audit_trail` 落 `action=开户名偏航`，含当事人键与原因。
4. 入笼侧同口径：空名户（含遗产脏数据）禁止入笼，HTTP 409，同记 `开户名偏航`。
5. 对账面亮检测：`/api/reconcile` 汇总给出 `nameless_accounts`（无名正式户计数，恒应为 0），`/api/proof/{party}` 给出 `name_present`。

## 弃用口径（乙路径）

空名待补占位：本仓不建占位表。占位与正式名册并存易交叉，两套口径交叉将出现无名正式户，故乙路径弃用，不得与甲路径混用。

## 谢绝第三路

不允许「先开户后补名」「空名开户成功但标黄」等任何折中。禁止只改账户页星号装饰充数。

## 偏航处置

任何偏离本封板立场的开户/入笼请求，一律记 `开户名偏航` 并拒写。
